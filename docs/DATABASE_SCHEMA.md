# EcoTrack — PostgreSQL Database Schema & Normalization Guide

All core academic tables live in the `public` schema and are created idempotently by:
- `server/db/migrations/001_create_core_tables.sql`
- `server/db/migrations/002_create_session_table.sql`
- `server/db/migrations/003_emission_factor_metadata.sql`
- `server/db/migrations/004_analytics_indexes.sql`

---

## 1. Relational Schema Notation

- `users` (**id**, full_name, email, password_hash, created_at)
- `activity_types` (**id**, category, name, unit, is_active)
- `emission_factors` (**id**, *activity_type_id*, factor_kg_co2e_per_unit, unit, source, source_url, reference_year, effective_date, geographic_scope, notes, created_at)
- `activity_logs` (**id**, *user_id*, *emission_factor_id*, quantity, calculated_co2e, activity_date, created_at)
- `monthly_goals` (**id**, *user_id*, goal_month, target_co2e, created_at)

*(Bold = Primary Key; Italic = Foreign Key)*

## 2. Table Definitions & Constraints

### 2.1 `users`
| Column | Data Type | Constraints | Purpose |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Surrogate user ID |
| `full_name` | `VARCHAR(150)` | `NOT NULL`, `CHECK (LENGTH(TRIM(full_name)) >= 2)` | User display name |
| `email` | `VARCHAR(255)` | `NOT NULL`, `UNIQUE (uq_users_email)`, `CHECK (email = LOWER(TRIM(email)))` | Normalized login email |
| `password_hash` | `TEXT` | `NOT NULL` | Salted bcrypt hash (cost 12) |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Account creation timestamp |

### 2.2 `activity_types`
| Column | Data Type | Constraints | Purpose |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Surrogate activity type ID |
| `category` | `VARCHAR(50)` | `NOT NULL`, `CHECK (category IN ('Transportation', 'Energy', 'Lifestyle'))` | Domain category |
| `name` | `VARCHAR(150)` | `NOT NULL`, `UNIQUE (category, name)` | Human-readable activity name |
| `unit` | `VARCHAR(30)` | `NOT NULL`, `CHECK (LENGTH(TRIM(unit)) > 0)` | Canonical unit (`km`, `kWh`, `kg`, `meals`) |
| `is_active` | `BOOLEAN` | `NOT NULL DEFAULT TRUE` | Soft-enable toggle |

### 2.3 `emission_factors`
| Column | Data Type | Constraints | Purpose |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Surrogate factor version ID |
| `activity_type_id` | `BIGINT` | `NOT NULL`, `REFERENCES activity_types(id) ON DELETE RESTRICT` | Parent activity type |
| `factor_kg_co2e_per_unit` | `NUMERIC(16,8)` | `NOT NULL`, `CHECK (factor_kg_co2e_per_unit >= 0)` | High-precision conversion factor |
| `unit` | `VARCHAR(30)` | Nullable (added in Migration 003) | Unit verification metadata |
| `source` | `TEXT` | `NOT NULL`, `CHECK (LENGTH(TRIM(source)) > 0)` | Official publication citation |
| `source_url` | `TEXT` | Nullable (added in Migration 003) | Citation URL |
| `reference_year` | `INTEGER` | Nullable (added in Migration 003) | Factor publication year |
| `effective_date` | `DATE` | `NOT NULL` | Effective start date |
| `geographic_scope` | `TEXT` | Nullable (added in Migration 003) | Regional applicability |
| `notes` | `TEXT` | Nullable (added in Migration 003) | Boundary & scope assumptions |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Row insert timestamp |
- **Unique Constraint**: `uq_emission_factors_version UNIQUE (activity_type_id, effective_date, source)`

### 2.4 `activity_logs`
| Column | Data Type | Constraints | Purpose |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Surrogate log ID |
| `user_id` | `BIGINT` | `NOT NULL`, `REFERENCES users(id) ON DELETE CASCADE` | Owning user |
| `emission_factor_id` | `BIGINT` | `NOT NULL`, `REFERENCES emission_factors(id) ON DELETE RESTRICT` | Exact factor used for auditability |
| `quantity` | `NUMERIC(14,3)` | `NOT NULL`, `CHECK (quantity > 0)` | Activity quantity entered by user |
| `calculated_co2e` | `NUMERIC(18,6)` | `NOT NULL`, `CHECK (calculated_co2e >= 0)` | Server-calculated emissions (`kg CO2e`) |
| `activity_date` | `DATE` | `NOT NULL` | Calendar date of activity |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Log creation timestamp |

### 2.5 `monthly_goals`
| Column | Data Type | Constraints | Purpose |
| :--- | :--- | :--- | :--- |
| `id` | `BIGINT` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Surrogate goal ID |
| `user_id` | `BIGINT` | `NOT NULL`, `REFERENCES users(id) ON DELETE CASCADE` | Owning user |
| `goal_month` | `DATE` | `NOT NULL`, `CHECK (EXTRACT(DAY FROM goal_month) = 1)` | First day of target month (`YYYY-MM-01`) |
| `target_co2e` | `NUMERIC(14,3)` | `NOT NULL`, `CHECK (target_co2e > 0)` | Monthly emission ceiling (`kg CO2e`) |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL DEFAULT NOW()` | Creation timestamp |
- **Unique Constraint**: `uq_monthly_goals_user_month UNIQUE (user_id, goal_month)`

## 3. Indexes Implemented

| Index Name | Table | Definition | Query Optimization |
| :--- | :--- | :--- | :--- |
| `idx_activity_types_category_active` | `activity_types` | `(category, is_active)` | Speeds up active catalog loading |
| `idx_emission_factors_type_effective` | `emission_factors` | `(activity_type_id, effective_date DESC)` | Fast lookup of latest effective factor for a date |
| `idx_activity_logs_user_date` | `activity_logs` | `(user_id, activity_date DESC)` | User-scoped monthly/daily date range queries |
| `idx_activity_logs_factor_id` | `activity_logs` | `(emission_factor_id)` | Join acceleration & `RESTRICT` delete checks |
| `idx_activity_logs_user_co2e` | `activity_logs` | `(user_id, calculated_co2e DESC)` | Emission-range filtering & sorting |
| `idx_activity_logs_user_recent` | `activity_logs` | `(user_id, activity_date DESC, created_at DESC, id DESC)` | Dashboard recent 5 activities & deterministic pagination |
| `idx_monthly_goals_user_month` | `monthly_goals` | `(user_id, goal_month DESC)` | Monthly target lookup & history ordering |
| `IDX_session_expire` | `session` | `(expire)` | Expired session cleanup |

## 4. Normalization Justification (1NF -> 2NF -> 3NF)

- **First Normal Form (1NF)**: Every table stores atomic scalar values (no comma-separated activity lists, arrays, or nested repeating columns), and every table has a primary key (`id`).
- **Second Normal Form (2NF)**: Every table uses a single-column primary key (`id`), eliminating any possibility of partial functional dependencies on composite keys.
- **Third Normal Form (3NF)**: Every non-key column depends strictly on its primary key (`the key, the whole key, and nothing but the key`), with no transitive dependencies:
  - `activity_logs` does **not** copy `category`, `name`, `unit`, or `source`; it references `emission_factor_id`.
  - `emission_factors` does **not** duplicate `category` or `name`; it references `activity_type_id`.
  - Note on `calculated_co2e`: Although derived from `quantity × factor_kg_co2e_per_unit`, persisting `calculated_co2e` alongside `emission_factor_id` is an intentional audit-trail snapshot so historical monthly analytics and CSV exports remain immutable and fast without floating-point drift.
